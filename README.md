# Parsley's Farm v6

Farm records for Parsley's Farm, Kitengela: beds by hydrant section, planting, sprays and feeds, harvests, sales, expenses and GAP reports. Works offline and syncs when there is signal.

- **Setup:** see [SETUP.md](SETUP.md)
- **Demo:** with `js/config.js` left empty, the app runs on sample data. Nothing is saved.

## How it's built
- Plain HTML, CSS and JavaScript. No build step. Hosted on GitHub Pages.
- Supabase for the database, sign-in by email code, and photo storage.
- Every change is saved on the phone first, then sent in order from an outbox. Nothing leaves the outbox until Supabase confirms it.
- Database rules (row level security) decide who can see and change what. The Expenses PIN is checked by the database, not stored in the code.
